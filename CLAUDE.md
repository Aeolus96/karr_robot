# CLAUDE.md

Monorepo for the K.A.R.R. swerve robot. ROS 2 Jazzy, Ubuntu 24.04. Robot computer: Jetson AGX Orin (arm64).
Dev laptops: x86 Windows/Ubuntu, Apple Silicon macOS. Keep everything arch- and OS-agnostic.

- ROS 2 packages live at the repo top level (`karr_description/`, ...). The repo is cloned into `~/ros2_ws/src/karr_robot`
  on the robot and is mounted at the same path in the dev container.
- `urdf_prep/` (COLCON_IGNORE): raw SolidWorks export + `tools/convert_sw_export.py`. `karr_description/urdf/karr.urdf`,
  `config/footprint.yaml` and `meshes/` are GENERATED by it. Change values in the script's CONFIG section, never in the
  generated files. Then `./dev.sh verify`. Decisions/open items: `urdf_prep/NOTES.md`.
- Dev container: `./dev.sh <cmd>` (Linux/macOS/WSL) or `.\dev.ps1 <cmd>` (Windows). Run commands inside with
  `docker compose -f docker/compose.yaml exec ros ws-env bash -c "<cmd>"` (ROS + workspace sourced).
- From PowerShell, avoid inline double-quoted shell pipelines; put multi-step checks in a script.
- Follow REP-103/REP-105. Frame and joint reference: `karr_description/README.md`.
- Never run anything that moves hardware or touches the robot network without asking.
